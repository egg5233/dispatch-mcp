# archive/

Documents that are finished and no longer referenced. **Not tracked in git** (see `.gitignore`).

- Bucket by month of last change: `archive/YYYY-MM/<original filename>`.
- Policy: a document untouched for 60 days and not linked from an active runbook/design moves here.
  Session checkpoints, handoffs and handovers go here as soon as the session is over.
- Source code, patches and diffs that landed here as review material belong in their git repo;
  note the repo in the coordination README's "archived source" table when you archive them.
